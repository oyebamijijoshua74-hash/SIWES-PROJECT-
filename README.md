# SIWES Cybersecurity Project

An interactive, educational web platform focused on modern cybersecurity awareness, cyber defense strategies, phishing detection, password security, and online safety best practices.

## 🚀 Features

- **Cybersecurity Fundamentals & Threat Awareness**: Comprehensive guides on modern cyber threats, defense tactics, and incident response.
- **Phishing Simulation & Detection**: Interactive modules educating users on identifying suspicious emails, spoofed domains, and social engineering attacks.
- **Password Security & Strength Checker**: Real-time evaluation of password complexity, entropy, and credential best practices.
- **Online Safety & Digital Hygiene**: Practical tips and checklists for securing devices, accounts, and private data.
- **Clean, Modern UI**: Responsive, accessible, and fast static architecture.

## 📁 Project Structure

```
├── index.html          # Main landing and overview
├── defense_guide.html  # Comprehensive defense and countermeasure guide
├── phishing.html       # Phishing awareness and simulation
├── passwords.html      # Password security tools and guides
├── safety.html         # Personal cybersecurity and safe browsing tips
├── style.css           # Global stylesheets and modern theme
├── script.js           # Interactive components, validators, and dynamic logic
├── cyber_hero.jpg      # Hero image asset
└── serve.ps1           # Optional local development server (PowerShell)
```

## 💻 Running Locally

### Option 1: Direct File Opening
Double-click `index.html` to open it in any web browser.

### Option 2: PowerShell Server
Run the built-in PowerShell web server script:
```powershell
.\serve.ps1
```
Then visit `http://localhost:8000/`.

### Option 3: VS Code / Any Static Server
Use the Live Server extension or `npx serve .`

## 🌐 Deployment
This project is configured for one-click deployment on **Render**, **GitHub Pages**, **Vercel**, or **Netlify** as a Static Site.
